## Description

Ce projet est une extension d’un **système de messagerie distribuée** développé en Java.  
Il met en œuvre plusieurs composants réseau et applicatifs permettant l’envoi, la réception, la consultation et l’administration des emails dans une architecture distribuée.

Le système repose sur :

- un **serveur SMTP** pour l’envoi des messages,
- un **serveur POP3** pour la récupération des emails,
- un **serveur IMAP** pour une gestion avancée des boîtes mail,
- un **serveur d’authentification RMI**,
- une **base de données MySQL** pour le stockage centralisé,
- une **interface Web** pour l’accès via navigateur,
- des **clients JavaMail** pour tester SMTP / POP3 / IMAP,
- un mécanisme de **load balancing** avec **NGINX / HAProxy**.

Le sujet du TP demande justement d’étendre une plateforme Java existante avec IMAP, une interface Web, des clients applicatifs standards, et une architecture scalable avec répartition de charge. :contentReference[oaicite:0]{index=0} :contentReference[oaicite:1]{index=1} :contentReference[oaicite:2]{index=2} :contentReference[oaicite:3]{index=3}

## Fonctionnalités principales

### 1. Protocoles de messagerie
- Envoi d’emails via **SMTP**
- Récupération de messages via **POP3**
- Consultation avancée via **IMAP**
- Gestion des commandes de base IMAP :
  - `LOGIN`
  - `SELECT`
  - `FETCH`
  - `STORE`
  - `SEARCH`
  - `LOGOUT` :contentReference[oaicite:4]{index=4}

### 2. Authentification distribuée
- Vérification des identifiants via **Java RMI**
- Création, modification et suppression de comptes utilisateurs
- Intégration des serveurs SMTP / POP3 / IMAP avec le service d’authentification :contentReference[oaicite:5]{index=5}

### 3. Base de données MySQL
- Centralisation des utilisateurs et des emails
- Stockage des messages côté serveur
- Récupération des messages via POP3 / IMAP

  - l’authentification,
  - l’insertion d’emails,
  - la récupération,
  - la suppression,
  - la mise à jour des mots de passe. :contentReference[oaicite:6]{index=6}

## Architecture générale

Le système suit une architecture distribuée où plusieurs services collaborent :

- **Client** → envoi/réception d’emails
- **Serveur SMTP** → envoi des messages
- **Serveur POP3 / IMAP** → récupération et consultation
- **Serveur RMI** → authentification
- **Base de données MySQL** → stockage centralisé
- **Interface Web / API REST** → accès navigateur
- **Load Balancer** → distribution des requêtes
